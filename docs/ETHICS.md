# Consent and fair use

Voice cloning is a tool that can hurt people. These are the rules this project is published under. Most of them are also conditions of the model licence, so breaking them ends your right to use the model.

## Do

- Clone **your own voice**.
- Clone someone who gave **explicit, written consent** for this exact use. Keep the message or the signed line. The model licence requires you to be able to show it for public or commercial use.
- Use **designed, fictional voices** for characters.
- **Credit the model** on everything you publish: `This audio was created with Boson AI's Higgs Audio — https://www.boson.ai/higgs-audio`
- **Label AI voice** where the platform asks. If a listener would feel tricked on finding out, disclose.

## Do not

- Clone anyone without consent. Public figures, colleagues, family members, clients, former clients, the dead.
- Use a clone to make someone appear to say something they did not say.
- Use it for calls, voice notes or messages meant to pass as a real person. That is fraud in most countries.
- Use it for political persuasion or to imitate officials or candidates.
- Try to beat voice authentication.

## If someone asks you to remove their voice

Delete the reference clip, the transcript and every take. Do it the same day.

## Reporting misuse of this repository

Open an issue, or contact the maintainer through the GitHub profile. Forks that add features meant to hide the origin of audio or to bypass consent are not welcome upstream.
